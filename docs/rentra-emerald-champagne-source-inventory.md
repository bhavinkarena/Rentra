> This is the pre-implementation audit inventory. Shared tokens, controls, skeletons and the specific exceptions identified here have since been migrated; see [implementation and verification](rentra-emerald-champagne-implementation.md) for current status. File/line references below describe the original source baseline.


Companion to the [design system and implementation guide](rentra-emerald-champagne-design-system.md).

**Baseline:** `7281378`, 29 September 2026. **Scope:** 544 source files, 44,376 lines under `app`, `components`, `lib`; all JavaScript/JSX parsed without errors. Brand exports and design/configuration references are listed separately.

This is a repository-wide static coverage and migration-ownership register, not a claim that every route was executed or every source line received a separate manual accessibility audit. The main guide records source-confirmed findings and targeted manual review. No authenticated browser coverage is implied. Section numbers below refer to the main guide.

For every entry: preserve API/permission/validation/booking behavior. “Inherits theme” does not mean no QA is required; it means change the shared visual owner first, then verify the route. Section 14 of the guide defines the runtime acceptance matrix.
