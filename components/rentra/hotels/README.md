# Hotel landing photography

`inspiration.json` selects five existing photos from the backend's
`india-hotel-catalog.json`. Each entry retains its actual hotel name, source page
and recorded reuse-rights status. These are editorial inspiration photos, not
claims that the pictured hotels are currently bookable. The hero and stay picker
display the hotel/source credit. Actual discovery cards continue to use their
own API-backed photography and rates.

Reuse rights are currently **unconfirmed**, as in the source catalogue. Confirm
permission before publishing these marketing images. No newly sourced stock
photography is used.
